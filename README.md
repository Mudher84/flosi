# Flosi — فلوسي

Flosi is the active Android-native personal finance project.

Current imported checkpoint: **v1.4 Premium RTL Home**.

## Current foundation
- Native Android / Kotlin / Jetpack Compose.
- Arabic RTL foundation and premium purple/white design direction.
- Room finance data layer.
- Accounts, people, transactions, budgets, goals, commitments, invoices and exports.
- Biometric gate and privacy option for recent-app/screenshot protection.
- Encrypted backup flow.
- PDF / XLSX / CSV export.

## Next product phase
The current checkpoint is **not the final global architecture**. The next phase will replace Iraq-specific defaults and hard-coded IQD formatting with a global locale and multi-currency system, strengthen security, and expand premium visual analytics/data tables.
