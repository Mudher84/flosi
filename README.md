# Flosi — فلوسي

Flosi is the active Android-native personal finance project.

Current source checkpoint: **v1.4 Premium RTL Home**.

## Current foundation
- Native Android / Kotlin / Jetpack Compose.
- Arabic RTL foundation and premium purple/white design direction.
- Room finance data layer.
- Accounts, people, transactions, budgets, goals, commitments and invoices.
- Biometric gate and privacy option for recent-app/screenshot protection.
- Encrypted backup flow.
- PDF / XLSX / CSV export.

## Next product phase
This checkpoint is a foundation, not the final global product. Next work will remove Iraq-specific defaults and hard-coded IQD presentation, introduce global locale and multi-currency architecture, strengthen the security model, and build premium visual analytics and data tables across the app.
